02 컴퓨터와 프로그램

문법 전에 “프로그램이 뭘 하는 물건인지”만 잡으면 뒤 설명이 전부 연결됩니다.

한 줄 비유

컴퓨터는 받은 정보(입력)를 계산·판단(처리)해서 결과(출력)를 보여 주고, 필요하면 기억(저장)하는 기계입니다. 프로그램은 그 일을 시키는 설명서입니다.

부품역할게임으로 치면
CPU명령 계산이동·충돌·점수 계산
RAM지금 쓰는 작업 공간플레이어 좌표, 임시 상태
저장장치오래 보관설치 파일, 세이브
GPU화면 그리기 연산캐릭터·이펙트 렌더
C++와 연결: 변수·배열·객체는 대부분 RAM 이야기고, 코드는 CPU가 실행하는 명령입니다. → 10 · 스택과 힙으로 이어집니다.

03 컴파일과 실행

사람이 쓴 글이 컴퓨터가 읽을 말로 바뀌는 과정입니다.

소스 → 실행 파일

C++ 파일은 사람이 읽기 좋은 텍스트입니다. 컴파일러가 이를 기계어(실행 파일)로 바꿉니다.

1
소스 코드 .cpp — 우리가 편집하는 파일
2
컴파일 — 문법 검사 + 기계어 변환 (에러 나면 여기서 멈춤)
3
실행 — OS가 프로그램을 메모리에 올리고 CPU가 실행
팁: “실행이 안 돼요”의 절반은 컴파일 에러입니다. 빨간 줄·터미널 메시지를 번역기라도 읽으면 성장이 빨라집니다.
보강 예정: OS별 설치·한 줄 컴파일 명령 (Windows / macOS / Linux)

04 첫 프로그램

모든 C++ 프로그램은 대략 main에서 시작합니다.

#include <iostream>   // 입출력 도구 상자

int main() {
    std::cout << "Hello!\n";  // 화면에 출력
    return 0;                 // 정상 종료
}
  • #include = 필요한 도구 가져오기
  • std::cout = 표준 출력(화면)
  • return 0 = “문제 없이 끝났어요”
  • std = 표준 라이브러리 네임스페이스 → 사전에서 검색
  • 이 repo의 src/hello.cpp로 첫 컴파일 확인

05 변수와 타입

변수 = 이름 붙인 상자. 타입 = 상자에 넣을 종류의 라벨.

타입무엇을 담나예시
int정수int hp = 100;
double실수double speed = 3.5;
bool참/거짓bool alive = true;
char문자 하나char grade = 'A';
std::string문자열std::string name = "Kim";
 
#include <iostream>
#include <string>

int main() {
    int level = 1;
    std::string name = "Hero";
    std::cout << name << " Lv." << level << "\n";
}
보강 예정: 자료형 대략 크기, signed/unsigned 한 줄 주의

06 연산자

값에 대해 계산·비교·논리를 수행하는 기호입니다.

  • 산술: + - * / %
  • 비교: == != < > <= >=
  • 논리: && 그리고, || 또는, ! 아님
  • =(넣기)와 ==(같은지) 혼동 주의
int a = 10;
int b = a + 5;        // 15
bool ok = (b >= 15);  // true
보강 예정: 증감 ++, 복합 대입 +=, 정수 나눗셈 함정

07 조건과 반복

if는 갈림길, for / while은 같은 일을 여러 번.

int hp = 30;
if (hp <= 0) {
    std::cout << "Game Over\n";
} else {
    std::cout << "Keep going\n";
}

for (int i = 0; i < 3; ++i) {
    std::cout << "tick " << i << "\n";
}
체크포인트: 짝수 판별, 구구단, 점수 등급 — 세 개 다 되면 08로.

08 함수

일을 묶은 레시피 카드. 복사 대신 이름으로 재사용합니다.

int add(int a, int b) {
    return a + b;
}

int main() {
    std::cout << add(2, 3) << "\n";  // 5
}
  • 입력(매개변수) → 처리 → 출력(return)
  • void = 돌려줄 값 없음
  • 함수 안 지역 변수는 함수가 끝나면 사라짐 → 10 · 스택

09 배열과 문자열

같은 종류 여러 개 = 배열, 글자 여러 개 = string을 먼저.

int scores[3] = {90, 80, 100};
std::string title = "cpp-study";
권장: C 스타일 배열보다 곧 나올 std::vector(13)가 실무에서 더 편합니다. 배열은 “연속 상자” 이미지만 잡으세요.

10 스택과 힙

둘 다 RAM. 차이는 누가 관리하고, 얼마나 오래 사느냐.

스택 (Stack)힙 (Heap)
관리자동 (함수 끝나면 정리)프로그래머 / 스마트 포인터
속도매우 빠름상대적으로 느림
용도지역 변수, 함수 인자크기·수명이 자유로운 데이터
비유계산용 메모지창고 대여 (반납 규칙 필요)
보강 예정: 메모리 한 줄 도식 (STACK / FREE / HEAP)

11 포인터와 참조

값 vs 그 값이 있는 곳. 화살표 그림이 목표입니다.

포인터는 주소를 담는 변수, 참조는 이미 있는 변수에 붙인 별명에 가깝습니다. 

int x = 10;
int* p = &x;   // p는 x의 주소
*p = 20;       // 찾아가서 x를 20으로

int& r = x;    // r은 x의 별명
r = 30;        // x도 30
왜 배우나: 배열·객체·엔진 API가 “주소로 연결”되는 경우가 많습니다.

12 구조체와 클래스

데이터 + 행동을 한 덩어리로 묶습니다.

struct Player {
    std::string name;
    int hp;

    void takeDamage(int dmg) {
        hp -= dmg;
        if (hp < 0) hp = 0;
    }
};

int main() {
    Player p{"Hero", 100};
    p.takeDamage(30);
}
  • 멤버 변수 = 상태, 멤버 함수 = 행동
  • struct / class — 기본 접근 권한 차이 (나중에 정리)
  • 게임 캐릭터·아이템이 거의 이 패턴
보강 예정: 생성자, public/private, 상속 맛보기

13 STL · vector

이미 있는 좋은 도구. 가장 먼저 vector.

#include <vector>
#include <iostream>

int main() {
    std::vector<int> scores = {90, 80, 100};
    scores.push_back(70);
    for (int s : scores) {
        std::cout << s << "\n";
    }
}
도구언제
vector가변 길이 목록 (최우선)
string문자열
map / unordered_map키 → 값 사전
algorithm정렬·탐색 등

14 new 와 delete

힙을 빌리고 반납하는 감각. 남용은 금물.

int* p = new int(42);
std::cout << *p << "\n";
delete p;
p = nullptr;  // 습관
현대 습관: raw new 대신 vector(13) / 스마트 포인터(15). 여기서는 “힙과 스택이 다르다”만 확실히.

15 스마트 포인터

메모리를 객체 수명에 묶어 자동 정리 (RAII).

  • unique_ptr — 소유자 하나 (기본 선택)
  • shared_ptr — 공유 소유 (남용 주의)
  • weak_ptr — 순환 참조 끊기
#include <memory>
auto p = std::make_unique<int>(42);
// 스코프 끝에서 자동 해제
보강 예정: 규칙 오브 파이브, 순환 참조 그림

16 이동(move)

큰 데이터를 복사하는 대신 소유권을 이전합니다.

  • 복사 = 내용 복제 (비용 큼)
  • 이동 = 소유권 이전 (std::move)
  • vector가 커질 때 내부적으로 이런 최적화를 많이 씀

17 템플릿

타입을 파라미터로. 같은 로직을 복붙하지 않고 일반화. STL의 기반.

template <typename T>
T max2(T a, T b) {
    return (a > b) ? a : b;
}
// max2(1, 2); max2(1.5, 0.2);
보강 예정: 함수 템플릿 vs 클래스 템플릿, 컴파일 타임 타입
