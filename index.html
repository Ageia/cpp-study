C++ 한눈에 배우기

C++는 “컴퓨터에게 일을 시키는 아주 자세한 설명서”를 쓰는 언어입니다. 이 문서는 전문 용어를 최대한 풀어서, 처음 보는 사람도 흐름을 잡고 중급·고급으로 어디까지 가면 되는지 한 페이지에서 볼 수 있게 정리했습니다.

대상: 완전 초보 ~ 실무 입문 읽는 순서 = 학습 순서 코드는 개념 확인용 최소 예시
C++란? 전체 지도 초보 중급 고급 언어 비교 연습법 FAQ

1 C++는 뭐 하는 언어인가요?

쉬운 비유

요리를 레시피로 적는다고 생각해 보세요. 파이썬 같은 언어는 “맛있는 찌개 끓여줘”에 가깝고, C++는 “냄비에 물 500ml, 불 중불, 3분…”처럼 단계와 자원을 더 세밀하게 적습니다.

그래서 게임 엔진(언리얼), 고성능 서버, 임베디드, 그래픽처럼 속도·메모리를 직접 다루고 싶을 때 자주 쓰입니다.

한 줄로 기억

  • 프로그램 = 데이터 + 그 데이터를 바꾸는 명령
  • C++ = 명령을 빠르고 세밀하게 쓸 수 있는 도구
  • 강력한 만큼, 실수(잘못된 메모리 등)도 직접 책임
  • 한 번에 다 외우지 말고 단계별로 쌓기
목표: “코드를 읽을 수 있다 → 작은 프로그램을 만든다 → 왜 이렇게 쓰는지 안다” 순서로 가면 됩니다.

3 초보 — 프로그램의 뼈대 Beginner

3-1. 최소 프로그램

모든 C++ 프로그램은 대략 “시작점 main”에서 출발합니다.

#include <iostream>   // 입출력 도구 상자

int main() {
    std::cout << "Hello!\n";  // 화면에 출력
    return 0;                 // 정상 종료
}
읽기: #include = 필요한 도구 가져오기, std::cout = 표준 출력(화면), return 0 = “문제 없이 끝났어요”.

3-2. 변수 = 이름을 붙인 상자

컴퓨터 메모리에 값을 담아 두고, 이름으로 꺼내 씁니다. 타입은 상자에 “어떤 종류”를 넣을지 정하는 라벨입니다.

타입무엇을 담나예시
int정수int hp = 100;
double실수double pi = 3.14;
bool참/거짓bool alive = true;
char문자 하나char grade = 'A';
std::string문자열std::string name = "Kim";
 
#include <iostream>
#include <string>

int main() {
    int level = 1;
    std::string name = "Hero";
    std::cout << name << " Lv." << level << "\n";
}

3-3. 조건과 반복 — 흐름 제어

if는 갈림길, for/while은 “몇 번 또는 조건이 참인 동안” 반복입니다.

int hp = 30;
if (hp <= 0) {
    std::cout << "Game Over\n";
} else {
    std::cout << "Keep going\n";
}

for (int i = 0; i < 3; ++i) {
    std::cout << "tick " << i << "\n";
}
  • 비교: == != < > <= >=
  • 논리: &&(그리고) ||(또는) !(아님)
  • 초보 때 =(대입)와 ==(같은지) 혼동 주의

3-4. 함수 — 일을 묶은 레시피 카드

같은 코드를 복사하지 않고, 이름 붙인 블록으로 재사용합니다.

int add(int a, int b) {
    return a + b;
}

int main() {
    std::cout << add(2, 3) << "\n";  // 5
}
초보 체크포인트: 입력 → 처리 → 출력이 보이는 작은 프로그램을 3개 이상 스스로 만들어 보세요. (예: 짝수 판별, 구구단, 점수 등급)

4 중급 — 메모리와 구조 Intermediate

4-1. 포인터·참조 — “값” vs “그 값이 있는 곳”

변수 이름 뒤에는 실제 메모리 주소가 있습니다. 포인터는 그 주소을 담는 변수이고, 참조는 “이미 있는 변수에 붙인 별명”에 가깝습니다. 

int x = 10;
int* p = &x;   // p는 x의 주소
*p = 20;       // 주소로 찾아가 x를 20으로
// 이제 x == 20

int& r = x;    // r은 x의 별명
r = 30;        // x도 30
왜 배우나: 배열, 문자열, 객체, 게임 엔진 API가 전부 “주소로 연결”되는 경우가 많습니다. 지금 100% 숙달보다, 그림으로 주소 화살표를 그릴 수 있는 것이 목표입니다.

4-2. 구조체·클래스 — 데이터 + 행동 묶기

관련 있는 데이터를 한 덩어리로 묶고, 그 데이터에 하는 일을 멤버 함수로 붙입니다.

struct Player {
    std::string name;
    int hp;

    void takeDamage(int dmg) {
        hp -= dmg;
        if (hp < 0) hp = 0;
    }
};

int main() {
    Player p{"Hero", 100};
    p.takeDamage(30);
}
  • struct / class — 묶음의 이름
  • 멤버 변수 = 상태, 멤버 함수 = 행동
  • 중급에서 “객체 지향” 용어는 나중에 정리해도 됨. 먼저 묶어서 쓰기

4-3. STL 맛보기 — 이미 있는 좋은 도구

STL은 C++ 표준 라이브러리의 자료구조·알고리즘 모음입니다. 중급부터 vector를 최우선으로 익히세요.

#include <vector>
#include <iostream>

int main() {
    std::vector<int> scores = {90, 80, 100};
    scores.push_back(70);           // 뒤에 추가
    for (int s : scores) {          // 범위 기반 for
        std::cout << s << "\n";
    }
}
도구언제
vector가변 길이 목록 (가장 먼저)
string문자열
map / unordered_map키 → 값 사전
algorithm정렬·탐색 등

4-4. new/delete 감각 (그리고 왜 조심하나)

때로는 프로그램 실행 중에 메모리를 빌립니다(new). 빌렸으면 돌려줘야 합니다(delete). 안 돌리면 누수, 잘못된 주소를 쓰면 크래시가 납니다. 

int* p = new int(42);  // 힙에 int 하나
std::cout << *p << "\n";
delete p;              // 반납
p = nullptr;           // dangling 방지 습관
현대 실무: 가능하면 raw new 대신 vector / 스마트 포인터(고급 장)를 씁니다. 중급에서는 “힙과 스택이 다르다” 정도만 확실히.

5 고급 — 현대 C++와 설계 감각 Advanced

“고급”은 문법 자랑보다 안전·명확·성능을 동시에 잡는 쪽입니다. 처음엔 개념만 훑어도 됩니다.

5-1. 스마트 포인터

메모리를 객체 수명에 묶어 자동 정리합니다.

  • unique_ptr — 소유자 하나 (기본 선택)
  • shared_ptr — 공유 소유 (남용 주의)
  • weak_ptr — 순환 참조 끊기
#include <memory>
auto p = std::make_unique<int>(42);
// 스코프 끝에서 자동 delete

5-2. 이동(move) 의미론

큰 데이터를 “복사” 대신 “소유권 이전”으로 넘겨 비용을 줄입니다. std::move, 이동 생성자를 검색어로 남겨 두세요.

  • 복사 = 복사비 듦
  • 이동 = 자원 포인터만 넘기는 그림
  • 중급 vector가 내부적으로 이런 최적화를 많이 함

5-3. 템플릿 — 타입을 파라미터로

같은 로직을 int/double에 복붙하지 않고 일반화합니다.

template <typename T>
T max2(T a, T b) {
    return (a > b) ? a : b;
}
// max2(1, 2); max2(1.5, 0.2);

5-4. 그다음 갈래

  • 게임/언리얼: 객체 수명, UObject, 모듈 빌드
  • 알고리즘: 복잡도, STL 알고리즘
  • 시스템: 스레드, 락, 캐시 지역성
  • 공통: 코드 읽기 + 프로파일 전 측정 습관

6 다른 언어랑 뭐가 다른가

관점 C++ 파이썬 등
실행 보통 컴파일 후 네이티브 실행 → 빠름 인터프리터/VM 비중이 큼 → 배우기 쉬움
메모리 직접 다루는 선택권이 큼 가비지 컬렉션 등 자동 비중이 큼
실수 비용 잘못된 주소 접근 등 치명적일 수 있음 런타임 에러 메시지가 비교적 친절한 편
쓰임 엔진, 성능 필수 영역, 도구 체인 스크립트, 데이터, 웹, 자동화
선택 가이드: “빨리 아이디어 검증” → 파이썬 등, “성능·엔진·세밀한 제어” → C++. 둘 다 할 줄 알면 시야가 크게 넓어집니다.

8 FAQ

Q. C를 먼저 해야 하나요?

필수는 아닙니다. C++로 시작해도 됩니다. 다만 C 스타일 포인터·배열 개념은 중급에서 결국 만납니다.

Q. 어떤 표준을 보나요?

가능하면 C++17 이상 기준으로 자료를 보세요. 너무 오래된 튜토리얼만 보면 습관이 굳습니다.

Q. 언리얼 하려면 어디까지?

초보 문법 + 중급의 클래스/포인터/참조 감각이면 엔진 입문은 가능합니다. 고급은 엔진 코드 읽으면서 채워도 됩니다.

Q. 한 페이지로 충분한가요?

아니요. 이 문서는 지도와 첫 계단입니다. 각 키워드를 검색·책·문제로 확장하세요. repo의 src/·notes/에 직접 쌓으면 학습이 남습니다.
