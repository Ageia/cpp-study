## 가이드 구성 (왼쪽 목차)

| 구간 | 번호 | 주제 |
|------|------|------|
| 시작 | 01–04 | 학습 지도, 컴퓨터, 컴파일·헤더, 첫 프로그램·입출력 |
| 값과 흐름 | 05–09 | 변수, 연산자, 조건·enum·switch, 함수, 배열·string |
| 메모리와 구조 | 10–15 | 스택·힙, 포인터, class, 연산자 오버로딩, vector, new |

| 도구 | 20–21 | 용어 사전, 활용 예시·FAQ |
| 심화 | 22+ (예정) | 가상 메모리, 엔디안, vtable 등 |
